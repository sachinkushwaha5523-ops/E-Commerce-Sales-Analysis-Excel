# E-Commerce Sales & Performance Analysis Using Excel

## 📊 Project Overview

This project analyzes e-commerce sales data using Microsoft Excel to identify key business trends, profitability, customer behavior, regional performance, product category performance, and return patterns.

The objective is to transform raw e-commerce data into meaningful business insights that can support data-driven decision-making.

## 🎯 Business Objectives

* Analyze overall sales and profitability
* Identify high-performing product categories
* Analyze regional sales performance
* Track customer returns
* Identify loss-making categories
* Analyze payment-method performance
* Monitor monthly sales trends
* Evaluate delivery performance
* Create meaningful KPIs and visualizations

## 🔎 Key Insights

### Product Category

Electronics was the highest revenue-generating category with approximately ₹33.19 Lakh revenue.

### Regional Performance

The South region was the top-performing region with approximately ₹12.98 Lakh revenue.

### Return Analysis

Fashion recorded the highest return rate at approximately 8.3%, indicating a potential area for further investigation.

### Profitability

Grocery generated approximately ₹82K revenue but recorded a negative profit of approximately ₹9.2K, highlighting a potential pricing, discount, or cost-management issue.

### Payment Method

Credit Card was the most frequently used payment method, generating approximately ₹20.57 Lakh revenue.

### Monthly Performance

December 2024 recorded the highest monthly revenue at approximately ₹2.78 Lakh.
